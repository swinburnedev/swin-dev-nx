# @swinburne-dev/layout

This library exports the Layout component used across the Swinburne Dev portfolio application.

## Running unit tests

Run `nx test layout` to execute the unit tests via [Jest](https://jestjs.io).

## Running lint

Run `nx lint layout` to execute the lint via [ESLint](https://eslint.org/).

## Building

Run `nx build layout` to build the library.

## Publishing

See [Publishing to NPM](#publishing-to-npm) section in README.md.
